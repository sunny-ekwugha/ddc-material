# Cloud & DevOps Learning Resources

A hands-on collection of Cloud Engineering and DevOps learning materials, technical references, scripts, configuration files, and project exercises.

This repository covers the journey from Linux fundamentals and scripting to AWS cloud projects, CI/CD pipelines, containers, Kubernetes, and Infrastructure as Code.

## Getting Started

1. Begin with `01.Introduction` and `02.Prerequisites`.
2. Set up a suitable development environment using the virtual machine and operating system guides.
3. Follow the Linux, networking, Git, and scripting materials.
4. Explore the AWS and application deployment project folders.
5. Practice Docker, Kubernetes, CI/CD, Ansible, Terraform, and CloudFormation using the relevant examples.

## Working With the Materials

- Open the PDFs and reference files in their respective folders.
- Review scripts and configuration files before executing them.
- Check each project's prerequisites and environment-specific instructions.
- Use test environments for infrastructure and deployment exercises.
- Never commit passwords, access keys, tokens, or other secrets.

## Important Notes

This repository contains learning resources and hands-on examples. The exact setup and deployment procedures vary by project and environment. Consult the relevant files before running commands or deploying resources.
